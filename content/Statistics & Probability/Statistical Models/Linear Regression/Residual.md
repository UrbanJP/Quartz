The residual, or difference, is the distance between a data point and a fitted line. This value is useful for minimizing [[Residual Sum of Squares (RSS)]] for the [[Ordinary Least Squares]] method. To find the residual of a data point $(x_i, y_i)$ find the vertical distance between that point and the fitted line.


## Formal Definition
Given a set of data points $\{ (x_1,y_1), \, (x_2,y_2), \, \ldots , \, (x_n,y_n) \}$ and a fitted line $\hat y$, we define the residuals of each data point to be $\{ u_i \, |\,  u_i = y_i - \hat y_i \}$. Each $\hat y_i$ value is the $y$ value of the line $\hat y$ when $x=x_i$.
