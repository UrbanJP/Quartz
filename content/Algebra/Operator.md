An operation is a [[Function]] with two or more inputs but is usually a function with [[Arity]] 2. 


## Examples
Addition can be defined as a bivariate function $f: \mathbb{R}^2 \to \mathbb{R}$. We can then write addition equations like *5+7=12* as $f(5,7) = 12$ or $+(5,7) = 12$. This operation is [[Closure|Closed]] under the [[Real Numbers]].
