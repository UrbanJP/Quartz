The support of a [[Probability Distribution]] is the [[Set]] of possible values. The support is exactly the same as the [[Sample Space]] in the discrete case, but not in the continuous case since for any [[Probability Density Function]] $P(X=x)=0$.


## Formal Definition
For a discrete [[Random Variable]] $X$, the support is $\{x | P(X = x) > 0 \}$. If $X$ is continuous, then the support of $X$ is $\{x \, | \, P(x- \delta < X < x + \delta) > 0 \}$ where $\delta$ is an arbitrarily small number greater than zero.

The motivation for the continuous case is that for all values of $x \, P(X=x)=0$. So instead we define a value $\delta$ to capture the [[Neighborhood]] of each $x$.
