A probability vector is a [[Vector]] of probabilities $(\alpha_1, \alpha_2, \ldots , \alpha_n)$. It is usually used to display all the possible values a [[Random Variable]] can take on.

## Formal Definition
A probability vector is a [[Vector]] of a [[Random Variable]] $X$ where $P(X=j) = \alpha_j$ for $j = 1,2,\ldots$. In essence, it is a list of probabilities $\alpha = (\alpha_1, \alpha_2, \ldots)$. Typically, the [[Index Set]] for all the $j$'s is the [[State Space]] $\mathbb{S}$.
