Monotonicity refers to the "direction" of a [[Function]]: whether or not it is increasing or decreasing. There are four types of monotonicity. If a function satisfies at least one then it is called a monotonic function.

Strictly Increasing
- A function $f: A \to B$ is strictly increasing if $\forall a_1,a_2 \in A [a_2 > a_1 \implies f(a_2) > f(a_1)]$ 

Strictly Decreasing
- A function $f: A \to B$ is strictly decreasing if $\forall a_1,a_2 \in A [a_2 > a_1 \implies f(a_2) < f(a_1)]$ 

Monotonically Increasing (Weakly Increasing)
- A function $f: A \to B$ is monotonically increasing if $\forall a_1, a_2 \in A [a_2 > a_1 \implies f(a_2) \geq f(a_1)]$

Monotonically Decreasing (Weakly Decreasing)
- A function $f: A \to B$ is monotonically decreasing if $\forall a_1, a_2 \in A [a_2 > a_1 \implies f(a_2) \leq f(a_1)]$
