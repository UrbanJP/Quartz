The codomain is all *possible* values a [[Function]] could theoretically produce. In the function $f: A \to B$, the codomain is $B$. 

The actual values in $B$ that the function outputs is the [[Image]].
## Examples
Let a function $f: \mathbb{R} \to \mathbb{R}$ be defined as $f(x) = x^2 -1$. The codomain is all real numbers, but this function does not output any number less than $-1$.
