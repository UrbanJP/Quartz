A well ordered set is a set where each [[Element]] can be placed in order from least to greatest. 

A well ordered set is a [[Set]] with an order [[Relation]] such that each non-empty [[Subset]] contains a [[Least Element]].

## Formal Definition
Consider a non-empty set $\Omega$ and an ordering relation. Then $\Omega$ is well-ordered if $$\forall S \in \mathscr{P}(\Omega), \, \exists \omega \in S \, \text{ such that } \, \forall x \in S \quad \omega \leq x$$
