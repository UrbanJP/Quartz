Same as [[Average]], but a weight is taken into account for each data point. This weight allows for some values to "weigh" more than others. For example, let's say we have the [[Set]] of data points $\{1,5,10 \}$. We can take the average $\frac{1+5+10}{3}$, but we can add a weight to $5$ such as $\frac{1+(3)5 +10}{3}$. Here, $5$ is weighted three times as much as the two other values.
