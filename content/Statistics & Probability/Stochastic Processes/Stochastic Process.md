A Stochastic Process is a random process.


## Formal Definition
A stochastic process is a collection of [[Random Variable|Random Variables]] $\{ X_t | t \in I \}$ where $I$ is an [[Index Set]] and each $X_t$ share the same state space. 

This index set is typically either $I = \{1, 2, \ldots , n\}$ for a finitely countable set, $I = \mathbb{N}$ for a countably infinite set, $I = \mathbb{R^+} \cup 0$ or $[0, \infty)$ for an uncountable set or  some [[Subset]] of the aforementioned [[Set|Sets]].

For many purposes it is best to think of a particular stochastic process from $Y_1, Y_2, \ldots$ as a random vector $(Y_{n_1}, Y_{n_2}, \ldots, Y_{n_d})$. Here each $n_i$ is a member of $I$. This is just the notation for picking out  $d$ random variables. For example if $n_1 = 3, n_2 = 5,$ and $n_3 = 7$ we have the vector $(X_3, X_5, X_7)$.
