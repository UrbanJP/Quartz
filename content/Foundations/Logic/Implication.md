An implication $(\implies)$ is a conditional [[Proposition]]. It is an "if ___ then ___" statement. 

## Examples
$A \implies B$
- If $A$ then $B$
- $A$ implies $B$
- $A$ only if $B$
- $B$ if $A$
Take the time to understand why all four of these statements are [[Equivalent]].

$((A \implies B) \implies C) \implies D$
- If if if $A$ then $B$ then $C$ then $D$
	- When conditionals are embedded like this it is best to use a different description of the conditional like the ones below
- If ($A$ implies $B$ only if $C$) then $D$ obtains
	- Here "obtains" is just a linguistic convention for the reader to understand. It is interchangeable with "occurs", "happens", or "is true". 
	- Notice that the phrase "$A$ implies $B$ 
	- only if $C$" can be treated as a proposition $M$ to make the proposition "If $M$ then $D$".
- $D$ is true if $A$ implies $B$ only if $C$
	- Translations can sometimes be ambiguous like in this case. This is why propositional logic is used to be clear. The above statement can mean either $((A \implies B) \implies C) \implies D$ or it can mean $((A \implies B) \implies D) \implies C$.
