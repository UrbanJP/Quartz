The ceiling function $\lceil x \rceil$ rounds any real number to the [[Integers|Integer]] greater than or equal to that number.

Compare with [[Floor Function]].

## Examples
1. $\lceil 3.4 \rceil = 4$
2. $\lceil 99.9 \rceil = 100$
3. $\lceil -4..8 \rceil = -4$
4. $\lceil 42 \rceil = 42$
5. $\lceil 2.0000000000001 \rceil = 3$
