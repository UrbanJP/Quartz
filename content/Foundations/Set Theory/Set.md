A set is a list of objects portrayed in curly brackets {}. The items in the set are called [[Element|Elements]] of a set. These elements can be any object, but in the realm of mathematics the elements are typically mathematical objects. The empty set is symbolized as $\emptyset$.


## Examples

$\{ a, b, c\}$
$\{f(x), g(x,y), h(x,y,z) \}$
$\{ \{ \} \}$
