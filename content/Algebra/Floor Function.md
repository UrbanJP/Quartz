The floor function $\lfloor x \rfloor$ of a number $x$ rounds the value to lowest [[Integers|Integer]] value less than or equal to $x$. This is the analogue to the [[Ceiling Function]].

## Examples
1. $\lfloor 3.1 \rfloor =3$
2. $\lfloor 4.5 \rfloor = 4$
3. $\lfloor 99.99999999 \rfloor = 99$
4. $\lfloor 51 \rfloor = 50$
