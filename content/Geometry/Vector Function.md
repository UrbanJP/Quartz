A vector function, or a vector-valued function, is a [[Function]] that takes an input, typically a [[Real Numbers|Real Number]] and outputs a [[Vector]]. These are often used to represent curves and shapes in space. 


## Examples
Let $\vec{r}(t)=<2,t>$ be a vector function that outputs [[Position Vector|Position Vectors]]. For each $t$-value, there is a vector output. The [[Point|Endpoint]] of this vector represents a point on the line. When combining all the endpoints together $\vec{r}(t)$ turns out to be the line $x=2$.
