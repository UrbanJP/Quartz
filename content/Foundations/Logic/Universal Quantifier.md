The universal quantifier $\forall$ denotes every element in a domain. It is often translated as "for all", "for every", "for each", or "for any".

## Examples
$\forall x \in \mathbb{R}$ 
- For every $x$ in the set of real numbers
- $\mathbb{R}$ represents the [[Set]] of [[Real Numbers]]
$\forall x \forall y (x=y \iff y=x)$ 
- For all x and y, x equals y if and only if y equals x
- $\iff$ represents a [[Biconditional]]
$\forall x \in \mathbb{N} \, \, \exists y \text{ such that } y=x+1$
- For all x in the set of [[Natural Numbers]], there exists a y such that y equals x plus 1
- $\exists$ is the [[Existential Quantifier]]
