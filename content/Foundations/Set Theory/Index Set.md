An index set $I$ is a [[Set]] used for indexing over an [[Operator]]. The most notable are summations $\sum$, unions $\bigcup$, products $\Pi$, and intersections $\bigcap$.


## Examples
Let $I= \{ 1, 2, 3 \}$ and let $A_1 = \{a\}$, $A_2 = \{b\}$, and $A_3 = \{c\}$. Then we can write $\bigcup_{i \in I}A_i$ which is the [[Union]] between $A_1$, $A_2$, and $A_3$. We can see that $\bigcup_{i \in I} A_i = \{a, b, c \}$.

Let $I = \mathbb{N}$. Then $\sum_{i \in I}x_i = x_1 + x_2 + \ldots$ for some variables $x_1, x_2, \ldots$
