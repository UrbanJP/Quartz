The power set of a set $A$, typically denoted $\mathscr{P}(A)$, is the set of all [[Subset|Subsets]] of the set $A$.

## Examples
Consider the set $A = \{ 1, 2 \}$. The power set $\mathscr{P}(A)$ would be: 
$$ \mathscr{P}(A) = \{ \{ 1 \}, \{ 2 \}, \{ 1, 2 \}, \emptyset\}$$
Note that for any set the empty set is always a subset.
