A relation represents a relationship between two or more elements in a [[Set|set]]. Some common relations include equality $(=)$, less than $(<)$, and greater than $(>)$. Relations are not restricted to mathematical objects. For example, in [[Set Theory]] we can construct the set of all people and define a relation $R$ to be "weighs more than". $R(Ryu, Ken)$ would mean "Ryu weighs more than Ken". 

Despite our intuitive understanding of relations *doing* *something*, like taking two things and comparing them, mathematically a relation is just a set and not a [[Function]], [[Operator]] or a similar mathematical object.

## Formal Definition
A relation $R$ is a set of [[Tuple|Tuples]] where each item in each tuple is an element of some set $X$. $R$ is said to be a relation over $X$. 

It's important to note that for each tuple in $R$ the order matters and each tuple must have the same [[Arity]].

## Notation
- $R(a,b)$ 
- $aRb$
	- A limited notation when it comes to relations of different arities
- $(a,b) \in R$ 
	- This notation helps emphasize that $R$ is in fact a set and not a function or any other related object
