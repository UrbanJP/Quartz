The cardinality of a set $A$ denoted as $|A|$ is the number of elements in that set.

## Examples
Let $A = \{ a, 1, 2, d, e \}$, then $|A| = 5$

Let $B = \{ 1, 2, 3, \ldots , n \}$, then $|B| = n$

Let $C = \{ 1, 3, 5, 7, \ldots \}$, then $|C| = \aleph_0$ where $\aleph_0$ is [[Aleph Null]] 

Let $D = \mathbb{R}$, then $|D| = \aleph_1$ where $\aleph_1$ is [[Aleph One]]
