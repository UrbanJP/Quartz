Infinity is not a number. Instead, infinity is defined in terms of [[Cardinality]] and Order. Cardinal infinities represent the size of an infinite [[Set]], or how many [[Element|Elements]] are in the set. Ordinal infinity represents the order of a particular value in a [[Sequence]] of numbers.
- It's important to distinguish sets and sequences here. For a set, no value can be repeated and order doesn't matter. The set $\{1,2,3,3,4,4,4\}$ is the same as $\{4,2,3,1\}$, but if the two were sequences, they would not be [[Equivalent]]. 


## Cardinal Infinities
Cardinal infinities deal with how many elements are in a set. Infinities are first defined as a size of a set $A$, then we determine if a set $B$ is infinite or equal to a particular infinity if we can form a [[Bijection]] between $A$ and $B$.

The first and smallest cardinal infinity is $\aleph_0 = |\mathbb{N}|$ which is the amount of [[Natural Numbers]].
